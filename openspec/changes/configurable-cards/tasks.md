# Tasks

Every task ends the same way, in addition to its own verification: `npm run check` passes, `/code-review` on that
task's changes reports no unfixed confirmed finding, and the task is committed (skipped when the task changed no
files). The review task at the end of each group then reviews the whole group's changes.
